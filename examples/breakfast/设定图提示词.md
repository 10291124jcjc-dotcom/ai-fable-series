# 设定图提示词

在即梦画布里：图片生成 → 比例 16:9 → 出 4 张挑 1 张 → 下载存到下面写的位置，节点留在画布里，以后每集都框选它们。

## 墨先生
存成 `refs/墨先生.jpg`。
```
2D 动画角色设定图，同一个拟人动物角色：左边是全身三视图（正面、侧面、背面），中间上方是一张脸部大特写，中间下方是 4 个说话时的表情（平静、挑眉、微笑、若有所思），右边是 2 个动作（坐在柜台后翻一本旧书；抬起翅膀，把最长的一根羽毛尖竖在喙前做「嘘」的手势）。排版干净，纯白背景，没有场景和道具，左上角写名字「墨先生」。
外形：拟人化的老乌鸦，和成年人一样高、直立行走；全身乌黑羽毛带一点蓝紫光泽，眉毛和下巴的羽毛是灰白色，略弯的黄色尖喙，一双半眯的琥珀色眼睛，戴一副细金属圆框眼镜；穿深蓝色双排扣长呢大衣、米色毛线围巾；翅膀末端的长羽毛像手指一样能拿东西。
复古手绘 2D 动画角色设定，粗细有变化的黑色描线，赛璐璐分层上色，柔和平光，所有格子里是同一个角色，脸、毛色、身材比例和衣服完全一致；是原创角色，不像任何已有的动画角色。
```

## 旧书店
存成 `refs/旧书店.jpg`。
```
场景设定图，没有任何人物，同一个地方的 2 个画面，左右两格：左边朝柜台拍，右边朝门口和橱窗拍。
旧书店：街角的旧书店：深色木书架摆满旧书，柜台上一盏绿色玻璃罩台灯、一台老式收银机和一只铜铃，橱窗外是下着小雨的老街。
复古手绘 2D 动画背景，赛璐璐上色，暖黄台灯光和冷色窗光对比，高清，几格是同一个地方，东西的位置能对上，画面里没有文字和商标。
```
