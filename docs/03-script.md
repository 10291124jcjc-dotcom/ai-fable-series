# 03 剧本架构

## 开头公式（每集都用，前 30 秒里完成）

| 节拍 | 谁 | 例子（早餐） |
| --- | --- | --- |
| 1. 小角色在做一件日常小事，随口说出那句大家都信的话 | 小角色 | 豆豆捧着一大碗麦片：「又不吃早饭？早餐可是一天最重要的一餐！」 |
| 2. 智者抬眼，**先不说话** | 智者 | （沉默，钟摆声） |
| 3. 智者问第一句：「谁告诉你的？」 | 智者 | 「谁告诉你的？」 |
| 4. 小角色：「大家都这么说啊。」 | 小角色 | |
| 5. 智者问第二句：「那大家，又是听谁说的？」 | 智者 | |
| 6. 小角色愣住 | 小角色 | 勺子停在嘴边 |
| 7. 智者做招牌「嘘」手势，不说话 | 智者 | 羽毛尖竖在喙前 |
| 8. 切到证据画面，智者画外音开讲：哪一年、谁、做了什么 | 智者（画外音） | 木壳收音机：「1944 年，美国一家卖早餐麦片的公司，打了一轮广告……」 |

每集的台词都要重写，只保留这个顺序。两句问话可以换说法（「这个数谁定的？」「最早是谁说的？」），但一定是**问两次，第二次问到源头**。

## 后面怎么走

| 位置 | 做什么 |
| --- | --- |
| 证据 | 一句台词配一个新画面（B-roll）：老收音机、传单、报告一本本落下、天平指针跳。智者是画外音，画面里不放他 |
| 回到场景 | 一句话总结源头（「是这轮广告，把它喊遍了全美国」） |
| 反常识的结果 | 一个研究数字或一个后果（「吃早餐的人，一天多吃了大约 260 大卡」） |
| 小角色的反应 | 回扣他开头手里的东西（「那我这碗……白吃了？」） |
| 不说死 | 智者一句话收住（「不是有害，只是没那么神」） |
| 结尾 | 智者再做一次「嘘」手势，回扣开头那句话（「下次再听到大家都这么说，先问一句：听谁说的？」） |

可选：结尾加一句评论区互动（「你还信过哪句『大家都这么说』？」）。

## 时长

即梦一次最多 30 秒，一段 8 个镜头。

| 时长 | 段数 | 怎么排 |
| --- | --- | --- |
| 30 秒 | 1 段 | 开头公式压到 4 个镜头（1+3、4+5 合并），剩下 4 个镜头讲证据和结尾 |
| 60 秒（默认） | 2 段 | 第 1 段 = 开头公式 8 拍；第 2 段 = 证据、结果、结尾 |
| 90 秒 | 3 段 | 中间多一段：第二个证据或一个反方向的说法 |

## 写进 episode.json

集级字段：`title`、`topic`、`belief`（开头那句话）、`reveal`（真相一句话）、`cover`（封面大字，10 个字以内）、`hooks`（前后呼应）、`next_topic`、`facts`。

每个镜头：

| 字段 | 写什么 |
| --- | --- |
| `dur` | 秒数，至少 2 秒；台词按每秒 4 到 5 个字算，沉默的镜头 3 到 3.5 秒 |
| `place` | 在哪。和有图场景的 `name` 一字不差时，会自动带上那张参考图 |
| `cast` | 画面里有谁；画外音的人不算 |
| `cast_note` | 特殊情况自己写（「没有墨先生，也没有豆豆，只有杂货店店员」） |
| `desc` | 景别、谁在哪、做什么 |
| `panel` | 分镜这一格和 `desc` 不一样时才写 |
| `lines` | 台词：`who`、`text`；画外音写 `"vo": true` |
| `sfx` | 音效 |
| `link` | 和上一个镜头是一个连续镜头时写怎么接；每段第 1 个镜头不能写 |
| `card` | 剪辑时加的字卡 |

段级字段：`title`、`continuity`（比如「豆豆一直捧着同一只大碗」）、`text_note`（哪些东西上不要有字）。
