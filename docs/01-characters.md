# 01 角色和固定场景

## 两个角色

| | 智者 | 小角色 |
| --- | --- | --- |
| 是谁 | 一只年长、安静、见过世面的动物 | 一只比他矮一截、热心又爱跟风的动物 |
| 作用 | 先不说话，再问两句，最后摆证据；从不讲大道理 | 观众的嘴：说出大家都信的那句话，被问住会愣，愿意改 |
| 招牌 | 一个固定的「嘘」手势（羽毛尖、爪子、蹄子竖在嘴前） | 手里总拿着这集话题的东西（一碗麦片、一瓶水、一个计步器） |

两个人一高一矮、一冷一热，站在一起一眼能分清。智者的戏份大多是画外音，画面里多给证据，不要让他从头讲到尾。

## 原创，不撞别人的号

这个架子来自外网「穿西装的狼 + 戴礼帽的猪」那一类号。**只学结构，不搬角色**：

- 不做狼 + 黑西装 + 红领带，不做猪 + 圆顶礼帽 + 马甲
- 不用别人号里的台词、口头禅、封面字体
- 动物、配色、衣服都换掉。下面三组随便挑，也可以自己定：

| | 智者 | 小角色 | 固定场景 |
| --- | --- | --- | --- |
| A（模板默认） | 墨先生：戴圆眼镜、穿深蓝大衣的老乌鸦 | 豆豆：穿草绿卫衣的胖仓鼠 | 街角旧书店 |
| B | 老白：穿粗花呢背心、拄手杖的老山羊 | 小满：戴黄色毛线帽的浣熊 | 深夜的面馆 |
| C | 灰婆婆：裹着紫披肩、戴老花镜的猫头鹰 | 阿嘟：背着双肩包的兔子 | 小镇杂货铺 |

## 外形怎么写

- `look` 写死：动物种类、站起来多高（和对方比）、毛或羽毛的颜色、眼睛、一样配饰（眼镜、围巾）、衣服颜色和款式
- 拟人动物最容易走样的是手：写清楚用什么「当手」（翅膀末端的长羽毛、前爪）
- `short` 一句简称，分镜里用
- `voice` 写清：性别、年龄感、语速、性格（「低沉、慢、略带沙哑的中年男声，话少」）
- 发海外：台词用英文，`lang_note` 改成「两个角色说英语，口型和台词对上」

## 设定图

`make_prompts.py SERIES sheets` 生成：白底，全身三视图 + 脸部特写 + 4 个表情 + 2 个动作（第二个动作就是招牌手势）。出图后检查：

- 每格是不是同一个角色：毛色、眼镜、衣服一致
- 有没有多手多脚、多出来的羽毛手指
- 和 `look` 对不对得上

## 固定场景

智者待的地方，每段都会回来。`views` 写两个角度，一张图里放左右两格，过肩镜头来回切时才对得上，而且只占一个参考图名额。
